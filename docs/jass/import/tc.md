# `//import` — 檔案匯入指令

`//import` 指令用於將另一個 JASS 檔案包含到目前的編譯單元中。
它必須出現在檔案的**最開頭**，在任何語言陳述式（`globals`、`function`、`type` 等）之前。

## 語法

```jass
//import path/to/file.j
```

* `//import` 必須從**第 0 欄**開始（沒有前導空格）。
* `//import ` 之後到行末的內容就是**檔案路徑**。
* `/` 和 `\` 都可以用作路徑分隔符。
* 路徑可以是**相對路徑**（從目前檔案所在目錄解析）或
  **絕對路徑**（如 `/usr/share/jass/common.j` 或 `C:/maps/lib.j`）。

## 範例

```jass
//import common/natives.j
//import utils/math.j

globals
    integer count = 0
endglobals
```

## 行為

| 特性 | 說明 |
|------|------|
| **順序** | 匯入按從上到下處理；被匯入檔案的宣告在指令下方可用。 |
| **循環** | 循環匯入會被偵測到並報告為錯誤。 |
| **Ctrl+Click** | 點擊路徑可在編輯器中開啟被匯入的檔案。 |
| **自動更新** | 當被匯入的檔案被重新命名或移動時，路徑會自動更新。 |

---

# `//import!` — 凍結匯入

`//import!` 的運作方式與 `//import` 完全相同，但會將目標檔案標記為
**凍結**（唯讀）。

```jass
//import! blizzard/common.j
```

## 與 `//import` 的差異

| | `//import` | `//import!` |
|-|------------|-------------|
| 拉取宣告 | ✅ 是 | ✅ 是 |
| 檔案可編輯 | ✅ 是 | ❌ 否 — 視為唯讀 |
| 用途 | 您自己的專案檔案 | SDK / 引擎檔案，不應修改 |

凍結檔案永遠不會被語言伺服器執行的自動重新命名、重構或其他寫入操作所修改。
