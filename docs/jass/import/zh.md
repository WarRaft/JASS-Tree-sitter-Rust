# `//import` — 文件导入指令

`//import` 指令用于将另一个 JASS 文件包含到当前编译单元中。
它必须出现在文件的**最开头**，在任何语言语句（`globals`、`function`、`type` 等）之前。

## 语法

```jass
//import path/to/file.j
```

* `//import` 必须从**第 0 列**开始（没有前导空格）。
* `//import ` 之后到行末的内容就是**文件路径**。
* `/` 和 `\` 都可以用作路径分隔符。
* 路径可以是**相对路径**（从当前文件所在目录解析）或
  **绝对路径**（如 `/usr/share/jass/common.j` 或 `C:/maps/lib.j`）。

## 示例

```jass
//import common/natives.j
//import utils/math.j

globals
    integer count = 0
endglobals
```

## 行为

| 特性 | 说明 |
|------|------|
| **顺序** | 导入按从上到下处理；被导入文件的声明在指令下方可用。 |
| **循环** | 循环导入会被检测到并报告为错误。 |
| **Ctrl+Click** | 点击路径可在编辑器中打开被导入的文件。 |
| **自动更新** | 当被导入的文件被重命名或移动时，路径会自动更新。 |

---

# `//import!` — 冻结导入

`//import!` 的工作方式与 `//import` 完全相同，但会将目标文件标记为
**冻结**（只读）。

```jass
//import! blizzard/common.j
```

## 与 `//import` 的区别

| | `//import` | `//import!` |
|-|------------|-------------|
| 拉取声明 | ✅ 是 | ✅ 是 |
| 文件可编辑 | ✅ 是 | ❌ 否 — 视为只读 |
| 用途 | 您自己的项目文件 | SDK / 引擎文件，不应修改 |

冻结文件永远不会被语言服务器执行的自动重命名、重构或其他写入操作所修改。
