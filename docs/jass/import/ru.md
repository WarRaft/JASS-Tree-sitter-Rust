# `//import` — Директива импорта файла

Директива `//import` позволяет подключить другой JASS-файл в текущую единицу
компиляции.  Она должна находиться **в самом начале** файла, до любых
языковых конструкций (`globals`, `function`, `type` и т.д.).

## Синтаксис

```jass
//import path/to/file.j
```

* Токен `//import` должен начинаться с **колонки 0** (без ведущих пробелов).
* Всё после `//import ` до конца строки — это **путь к файлу**.
* В качестве разделителя пути допускаются и `/`, и `\`.
* Путь может быть **относительным** (разрешается от директории текущего файла)
  или **абсолютным** (`/usr/share/jass/common.j` или `C:/maps/lib.j`).

## Пример

```jass
//import common/natives.j
//import utils/math.j

globals
    integer count = 0
endglobals
```

## Поведение

| Возможность | Описание |
|-------------|----------|
| **Порядок** | Импорты обрабатываются сверху вниз; декларации из импортированных файлов доступны ниже директивы. |
| **Циклы** | Циклические импорты обнаруживаются и отображаются как ошибки. |
| **Ctrl+Click** | Клик по пути открывает импортированный файл в редакторе. |
| **Авто-обновление** | При переименовании или перемещении импортированного файла путь обновляется автоматически. |

---

# `//import!` — Замороженный импорт

`//import!` работает точно так же как `//import`, но помечает целевой файл
как **замороженный** (только для чтения).

```jass
//import! blizzard/common.j
```

## Отличия от `//import`

| | `//import` | `//import!` |
|-|------------|-------------|
| Декларации подтягиваются | ✅ Да | ✅ Да |
| Файл можно редактировать | ✅ Да | ❌ Нет — считается только для чтения |
| Применение | Файлы вашего проекта | SDK / файлы движка, которые не нужно изменять |

Замороженный файл никогда не изменяется при авто-переименовании,
рефакторинге или других операциях записи, выполняемых языковым сервером.
