# `//set` — Директива настройки файла

Директива `//set` позволяет настраивать параметры языкового сервера для
конкретного файла.  Она должна находиться **в самом начале** файла,
рядом с директивами `//import`, до любых языковых конструкций.

## Синтаксис

```jass
//set <ключ> <значение>
```

* Токен `//set` должен начинаться с **колонки 0** (без ведущих пробелов).
* `<ключ>` — имя настройки (пробелы в ключе не допускаются).
* `<значение>` — всё после ключа до конца строки (пробелы обрезаются).

## Пример

```jass
//import common/natives.j
//set ref-tip 1

globals
    integer count = 0
endglobals
```

## Доступные настройки

| Ключ | Тип | По умолч. | Описание |
|------|-----|-----------|----------|
| `ref-tip` | `0 \| 1` | `0` | Показать / скрыть подсказки с ID ссылок рядом с каждым идентификатором. Полезно для отладки разрешения символов и рефакторинга переименований. |
| `type-tip` | `0 \| 1` | `0` | Показать / скрыть подсказки с аннотацией типа для переменных и параметров (напр. `: integer`, `: constant real array`). |
| `build-jass` | `<путь>` | `./` | Путь для сборки JASS. Объединяет всё дерево импортов в один `.j` файл: типы → native → globals → функции (в топологическом порядке) → `main`. Если путь — директория, добавляется `war3map.j`. Если путь указывает на `.w3x` или `.w3m` архив, скрипт записывается прямо в карту. |
| `build-as` | `<путь>` | `./` | Путь для сборки AngelScript. Та же логика слияния, но с синтаксисом `.as`. Конфликты с зарезервированными словами разрешаются добавлением числового суффикса. Если путь указывает на `.w3x` или `.w3m` архив, скрипт записывается прямо в карту. |
| `backup` | `<путь>` | `./` | Путь для резервной копии карты. Перед записью скрипта в `.w3x` / `.w3m` файл, копия оригинального архива сохраняется по этому пути с префиксом даты: `YYYY_MM_DD_ИмяФайла.w3x`. Если путь — директория, файл с датированным именем помещается в неё. |

## Поведение

* Настройки действуют только в пределах одного файла — они не
  распространяются через `//import`.
* Нераспознанные ключи принимаются без ошибок (для прямой совместимости).
* Отсутствующее значение вызывает предупреждение (warning).
