# `//set` — Директива налаштування файлу

Директива `//set` дозволяє налаштовувати параметри мовного сервера для
конкретного файлу.  Вона повинна знаходитися **на самому початку** файлу,
поруч із директивами `//import`, перед будь-якими мовними конструкціями.

## Синтаксис

```jass
//set <ключ> <значення>
```

* Токен `//set` повинен починатися з **колонки 0** (без початкових пробілів).
* `<ключ>` — назва налаштування (пробіли в ключі не допускаються).
* `<значення>` — все після ключа до кінця рядка (пробіли обрізаються).

## Приклад

```jass
//import common/natives.j
//set ref-tip 1

globals
    integer count = 0
endglobals
```

## Доступні налаштування

| Ключ | Тип | За замовч. | Опис |
|------|-----|------------|------|
| `ref-tip` | `0 \| 1` | `0` | Показати / сховати підказки з ID посилань поруч із кожним ідентифікатором. Корисно для відлагодження розв'язання символів та рефакторингу перейменувань. |
| `type-tip` | `0 \| 1` | `0` | Показати / сховати підказки з анотацією типу для змінних та параметрів (напр. `: integer`, `: constant real array`). |
| `build-jass` | `<шлях>` | `./` | Шлях для збірки JASS. Об'єднує все дерево імпортів в один `.j` файл: типи → native → globals → функції (у топологічному порядку) → `main`. Якщо шлях — директорія, додається `war3map.j`. Якщо шлях вказує на `.w3x` або `.w3m` архів, скрипт записується прямо в карту. |
| `build-as` | `<шлях>` | `./` | Шлях для збірки AngelScript. Та сама логіка злиття, але з синтаксисом `.as`. Конфлікти із зарезервованими словами розв'язуються додаванням числового суфікса. Якщо шлях вказує на `.w3x` або `.w3m` архів, скрипт записується прямо в карту. |
| `backup` | `<шлях>` | `./` | Шлях для резервної копії карти. Перед записом скрипта в `.w3x` / `.w3m` файл, копія оригінального архіву зберігається за цим шляхом з префіксом дати: `YYYY_MM_DD_ІмʼяФайлу.w3x`. Якщо шлях — директорія, файл з датованим ім'ям поміщується до неї. |

## Поведінка

* Налаштування діють лише в межах одного файлу — вони не
  поширюються через `//import`.
* Нерозпізнані ключі приймаються без помилок (для прямої сумісності).
* Відсутнє значення викликає попередження (warning).
