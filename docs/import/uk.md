# `//import` — Директива імпорту файлу

Директива `//import` дозволяє підключити інший JASS-файл до поточної одиниці
компіляції.  Вона повинна знаходитися **на самому початку** файлу, перед
будь-якими мовними конструкціями (`globals`, `function`, `type` тощо).

## Синтаксис

```jass
//import path/to/file.j
```

* Токен `//import` повинен починатися з **колонки 0** (без початкових пробілів).
* Все після `//import ` до кінця рядка — це **шлях до файлу**.
* Як роздільник шляху допускаються і `/`, і `\`.
* Шлях може бути **відносним** (розв'язується від директорії поточного файлу)
  або **абсолютним** (`/usr/share/jass/common.j` або `C:/maps/lib.j`).

## Приклад

```jass
//import common/natives.j
//import utils/math.j

globals
    integer count = 0
endglobals
```

## Поведінка

| Можливість | Опис |
|------------|------|
| **Порядок** | Імпорти обробляються зверху вниз; декларації з імпортованих файлів доступні нижче директиви. |
| **Цикли** | Циклічні імпорти виявляються та відображаються як помилки. |
| **Ctrl+Click** | Клік по шляху відкриває імпортований файл у редакторі. |
| **Авто-оновлення** | При перейменуванні або переміщенні імпортованого файлу шлях оновлюється автоматично. |

# `//import!` — Заморожений імпорт

`//import!` працює точно так само як `//import`, але позначає цільовий файл
як **заморожений** (лише для читання).

```jass
//import! blizzard/common.j
```

## Відмінності від `//import`

| | `//import` | `//import!` |
|-|------------|-------------|
| Декларації підтягуються | ✅ Так | ✅ Так |
| Файл можна редагувати | ✅ Так | ❌ Ні — вважається лише для читання |
| Застосування | Файли вашого проєкту | SDK / файли рушія, які не потрібно змінювати |

Заморожений файл ніколи не змінюється при авто-перейменуванні,
рефакторингу або інших операціях запису, що виконуються мовним сервером.
