# JASS Tree-sitter Rust

Так, назва буквально описує стек — граматика Tree-sitter, написана на Rust.  
JASS винесено на перший план заради уваги (і ностальгії), і, звісно, ми його повністю підтримуємо.

## Підтримувані мови

### [JASS](https://github.com/WarRaft/tree-sitter-jass) — `.j`, `.pld`

Основна мова скриптів WarCraft III. Повна підтримка на основі спеціальної граматики
[tree-sitter-jass](https://github.com/WarRaft/tree-sitter-jass).

### [AngelScript](https://github.com/WarRaft/tree-sitter-as) — `.as`

Підтримка AngelScript для модифікації WarCraft III на базі UJAPI. Граматика —
[tree-sitter-as](https://github.com/WarRaft/tree-sitter-as).

### [BNI](https://github.com/WarRaft/tree-sitter-bni) — `.bni`

**BNI** (Blizzard Notation Ini) — структурований формат конфігурації для модифікації Warcraft III.  
Граматика — [tree-sitter-bni](https://github.com/WarRaft/tree-sitter-bni).

### BLP — `.blp`

Вбудований переглядач зображень формату **BLP**, що використовується у WarCraft III.

## Система імпорту

Файли JASS можна зв'язувати між собою за допомогою спеціальних директив у коментарях:

```jass
//import path/to/file.j
//import! blizzard/common.j
```

- `//import` — зв'язує файл зі спільною областю видимості. Усі декларації верхнього рівня (функції, глобальні змінні, типи, нативки) стають доступними.
- `//import!` — **заморожений** імпорт. Те саме, що `//import`, але цільовий файл вважається доступним лише для читання і не буде змінений рефакторингом чи автоперейменуванням.

Директиви мають знаходитися на самому початку файлу, до будь-яких інструкцій мови.

### Можливості імпорту

- **Автодоповнення шляху** — підказки для шляхів файлів після `//import`.
- **Ctrl+Click** — відкриває імпортований файл у редакторі.
- **Діагностика невалідних шляхів** — неіснуючі шляхи підсвічуються як помилки.
- **Автооновлення при перейменуванні/переміщенні** — при перейменуванні або переміщенні імпортованого файлу шляхи в усіх файлах, що посилаються, автоматично оновлюються.
- **Кросплатформні шляхи** — `/` і `\` взаємозамінні; підтримуються відносні, абсолютні та Windows-шляхи (`C://`).
- **Виявлення циклів** — циклічні імпорти виявляються та повідомляються.

## `//set` — Конфігурація файлу

```jass
//set ref-tip 1
//set build-jass ./out/war3map.j
//set build-as ./out/war3map.as
```

| Ключ | Значення | Опис |
|------|----------|------|
| `ref-tip` | `1` / `0` | Показати / приховати вбудовані підказки з ID посилань біля кожного ідентифікатора — корисно для налагодження розв'язання символів. |
| `build-jass` | `<шлях>` | Шлях для JASS-збірки. Об'єднує все дерево імпортів в один `.j`-файл. |
| `build-as` | `<шлях>` | Шлях для AngelScript-збірки. Та сама логіка об'єднання, але із синтаксисом `.as`. |

## Міжфайловий інтелект

Усі файли, зв'язані через `//import`, утворюють **зв'язний компонент** — спільну глобальну область видимості:

- **Резолвер області видимості** — постійний O(1) пошук імен по всіх імпортованих файлах, зберігається між перезапусками сервера.
- **Двофазне розв'язання** — Фаза 1 розв'язує символи локально; Фаза 2 зв'язує нерозв'язані посилання із символами з імпортів.
- **Відстеження змін експорту** — повторний розбір залежних файлів відбувається лише при реальній зміні набору експортованих декларацій.
- **Push-діагностика** — помилки повідомляються для затронутих файлів негайно, навіть якщо вони не відкриті в редакторі.

## Граф викликів

Сервер будує граф викликів функцій по всьому зв'язному компоненту:

- **Виявлення невикористаних функцій** — функції, недосяжні з точок входу `main` / `config`, позначаються.
- **Виявлення циклів** — циклічні ланцюжки викликів повідомляються через діагностику.
- **Топологічне сортування** — використовується системою збірки для розміщення викликаних функцій перед викликаючими (вимога JASS).

Панель **Граф викликів** на D3.js доступна через кнопку в заголовку редактора.

---

## Візуалізація графа імпортів

Панель **Граф імпортів** на D3.js показує дерево залежностей поточного файлу. Доступна через кнопку в заголовку редактора. Усі ресурси візуалізації вбудовані — підключення до інтернету не потрібне.

## Система збірки

Директиви `//set build-jass <шлях>` та `//set build-as <шлях>` запускають збірку, яка:

1. Збирає всі файли з дерева імпортів.
2. Виконує топологічне сортування функцій.
3. Об'єднує все в один вихідний файл: **типи → глобальні змінні → функції → `main`**.
4. Пропускає оголошення `native` та визначення типів (вони надаються рушієм).
5. Вільні вирази верхнього рівня поміщуються в `main`.

## Постійне кешування

Усі важкі структури даних серіалізуються на диск через **bincode** та відновлюються при перезапуску сервера:

- **Граф імпортів** — граф залежностей файлів (на базі petgraph).
- **Резолвер області видимості** — глобальний індекс символів.
- **Кеш символів** — декларації функцій/змінних/типів по файлах.
- **Кеш посилань** — карти посилань по файлах.

Це означає майже миттєвий запуск навіть для великих проєктів.

## Архітектура

- **Tree-sitter** — інкрементальний парсинг для всіх підтримуваних граматик.
- **`ParseSnapshot`** — атомарний незмінний знімок усіх LSP-даних файлу, зберігається в `Arc<ParseSnapshot>` для конкурентного читання без блокувань.
- **`CancellationToken`** — скасування по файлу: нові правки негайно переривають застарілі задачі парсингу.
- **DashMap** — конкурентне сховище файлів для всіх знімків.
- **petgraph** — аналіз графів імпортів та викликів.

## Гарячі клавіші

Усі команди доступні через кнопки в заголовку редактора, але ви також можете призначити власні гарячі клавіші.

Відкрийте **Сполучення клавіш** (`Ctrl+K Ctrl+S` / `⌘K ⌘S`), знайдіть потрібну команду та призначте будь-яку комбінацію.

| ID команди | Опис |
|------------|------|
| `importGraph.show` | Показати граф імпортів |
| `callGraph.show` | Показати граф викликів |
| `build.execute` | Збірка (JASS / AngelScript) |

Або додайте прив'язки безпосередньо в `keybindings.json` (`Ctrl+Shift+P` → *Preferences: Open Keyboard Shortcuts (JSON)*):

```json
[
  { "key": "ctrl+shift+i", "command": "importGraph.show", "when": "resourceLangId == jass || resourceLangId == angelscript" },
  { "key": "ctrl+shift+g", "command": "callGraph.show",   "when": "resourceLangId == jass || resourceLangId == angelscript" },
  { "key": "ctrl+shift+b", "command": "build.execute",    "when": "resourceLangId == jass || resourceLangId == angelscript" }
]
```
